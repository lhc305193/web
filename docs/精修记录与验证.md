# 精修记录与验证（2026-10-16）

本记录说明本轮在交接基线上改了什么、实际检查了什么、哪些没能检查，以及仍然存在的缺口。基线已作为第一个提交保存（`Import baseline handoff …`），`当前网站预览.html` 与 `reference/current/` 未改动。

## 本轮方向

只做一个方向：**让产品名、一条有依据的关注理由和两个入口与盒装形成共同焦点；所有关键资料不依赖操作即可读；规格选择不经过其他规格。** 保留 Three.js / Vite 与现有盒装、银袋、摄影棚、灯光和程序贴图，没有换框架或另起模板。

## 实际做过的检查

环境：云端 Linux 容器，Node 22.22.0，Playwright 1.56 + Chromium（无 GPU，WebGL 由 SwiftShader 软件模拟）。

- `npm run build` 通过（16个模块）。`npm run preview:file` 生成单文件预览，并以 `file://` 直接打开确认首屏三维画面正常。
- 改后截图存于 `reference/refined/`（01—07），检查脚本为 `scripts/verify-interactions.mjs`。
- 截图检查视口：1280×720、1440×900、1024×768、768×1024、390×844、375×667。逐张查看了首屏、开盒段起点与取出后、选择依据、规格（3/16只装）。
- 自动交互脚本（Playwright）全部通过的项目：
  - 首屏 h1 为品名；比较对象与“薄度升级”相邻；两个入口分别指向 `#feel`、`#packs`。
  - 未操作时“袋里是什么”面板完整位于视口内。
  - 键盘：滑杆 End 取出、Home 放回；规格单选方向键切换。
  - “取出一只”按钮取出、文案变为“放回盒中”；鼠标在盒上向上拖动可取出。
  - 快速往下滚到底再回顶部，无报错。
  - 3/6/16 切换后摘要标题、数量、URL 参数 `?pack=`、去向说明一致，购买链接为官方精选店铺。
  - 页面文字中不再出现无依据的推荐语。
  - FAQ 单项展开、全部展开。
  - 全站外链只有三个官方地址（精选店铺、产品页、使用说明），均带 `rel=noopener`。
  - 浏览器“返回”回到上一段（`#feel`）。
  - 手机：首屏同时看得到品名、比较说明和两个入口；页头“选规格”可见；无横向溢出；菜单打开与 Esc 关闭；开盒段按40px网格探测手指落点，没有任何点位声明 `touch-action: none`（只有右侧滑杆这样声明，约占屏幕2.9%）。
  - 减少动态（`prefers-reduced-motion: reduce`）：取出立即完成，无报错。
  - 禁用 WebGL：显示 CSS 盒装回退；开盒段资料仍可读，无效的“取出一只”按钮被隐藏；规格切换正常。
  - 以上各场景无页面脚本错误（禁用 WebGL 时 Three.js 自身打印的“无法创建上下文”除外，属预期）。

## 没能检查或不能据此下结论的

- **帧率与流畅度**：容器内为软件渲染，测得约 0.5 帧/秒，只能说明本机无 GPU，不代表任何真实设备。真实桌面与手机的帧率、镜头过渡和规格切换手感需要在有 GPU 的设备上看。
- **真实触摸滚动**：Chromium 的合成触摸手势在此环境连纯文字区域也无法滚动（对照组同样失败），所以改为检查手指落点的 `touch-action`。真机滑动仍需在手机上试。
- **官方链接可达性**：容器网络无法访问 durex.com.cn，三个链接地址沿用交接资料（2026-10-16 核对），本轮没有重新打开确认。
- 屏幕阅读器朗读、Safari/Firefox、真实手机浏览器没有测试。
- 审美是否达标需要人看；构建通过和脚本通过都不代表画面合格。

## 仍然存在的缺口（需要素材或决定，未伪造）

1. **产品本体**：没有经过核对的卷状本体、完整陈列态和润滑表面实拍或合格 CG。本轮没有用透明圆片或玻璃片替代，开盒段和资料区都写明“暂无产品本体实拍”，结构只以线稿示意图表达。方案中的第一段（本体开场）和第四段（有限角度观察）因此没有启用。
2. **撕袋与取出影片**：没有真实手部拆封素材，所以没有做撕袋、袋口张开和本体露出；也就没有暂停/跳过/重看控件（没有可控制的影片，不放空按钮）。
3. **独立包装外观**：银袋仍是无印刷的程序示意，不是同款袋装实拍。
4. **16只装盒型**：仍是推测比例，页面标注“盒型未经核对”。
5. 官网包装图只有 500×500，只用于外观校准，没有放大使用。

取得以上素材后的接入点：本体与观察片段可放在 `#feel` 之后作为独立段落，使用 `<video>` 加海报帧，进度由按钮和有限范围拖动控制；撕袋片段接在“取出一只”之后单向播放。外部付费生成、素材购买或公开发布未在本轮进行。
