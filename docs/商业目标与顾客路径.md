# 商业目标与顾客路径

这是本次精修的首要判断标准，优先于具体镜头、技术和装饰偏好。

## 为什么做这个网站

将杜蕾斯 AiR Feel 当作一件真实商品，完整、有吸引力地展示给顾客。访客应看懂它是什么、拿来做什么、与自己的需要有什么关系、价值和好处在哪里、为什么值得考虑这一款，以及怎样继续选购。

网站面向的关键观众是刚到页面、没有看过任何背景、原本对这件商品没有特别兴趣的人。希望通过有吸引力的画面和有依据的介绍，让他产生“这个有意思，值得继续看”“这可能符合我的需要”“我愿意进一步考虑或选购”的判断。审美、动态和交互共同服务这条过程。

## 从冷淡到愿意考虑的完整过程

| 顾客此时的问题 | 网站应给出的具体内容 | 画面和互动的任务 |
| --- | --- | --- |
| 这是什么，为什么值得停留？ | 清楚品牌、具体品名、商品本身与一个关注理由 | 第一帧有完整广告构图和精致实物；短动作迅速给回报，不让人等很久才认出商品 |
| 与我有什么关系？ | 亲密关系中需要认真准备，同时对轻薄体验有偏好的选择情境 | 产品与关注点紧密关联，文字简短具体；情绪吸引不依赖空泛口号 |
| 我到底能得到什么？ | 看见完整实物、包装里的内容、形态与表面，以及已核实的特点 | 开袋真正接到本体；观察操作让人多看清细节，不以完成动作代替理解 |
| 为什么考虑这一款？ | 将轻薄偏好接到官方限定范围内的薄度升级，再提供材料、润滑类型与尺寸等选择依据 | 每个镜头对应一项具体认识，感官吸引与事实证据相互支持 |
| 我凭什么相信，适不适合？ | 实物一致性、资料来源、比较范围、材料与尺寸、必要使用信息 | 稳定阅读停点、可展开细节；不靠CG光泽、透光或拉伸冒充性能测试 |
| 感兴趣以后怎么选、怎么买？ | 清楚的3/6/16只数量选择、当前摘要与真实官方出口 | 不强制看完影片或玩完互动；入口始终可达，行动和所见选择对应 |

## 吸引力和购买理由怎样落地

视觉吸引要来自产品相关的形态、材质、光影和连续揭示。蓝银方向应形成一个有辨识度的整体，文字、产品、镜头不能各做各的。保留一个有内容回报的主互动，观众控制观看就能获得新的认识；不堆没有作用的粒子、液体和转圈。

关注这款的方向是对轻薄体验的偏好。官方薄度升级只比较上一代同系列，应保留其限定范围。透明与润滑型可以帮助理解产品，但它们不是已经证明胜过所有竞品的独有优势；材料与尺寸主要帮助判断适用性。不得为了让人想买而编造厚度、舒适性保证、绝对安全、竞品输赢、测评、销量、价格或评价。

把产品完整展示出来和让顾客愿意购买都要认真对待。页面即使能转动、能开盒，也不算表达完整；高精度模型本身也没有替代用途、价值和选择依据。

## 制作和验收时反复问的五件事

1. 一个没看过背景的人，第一眼能否认出具体商品，并愿意继续看？
2. 每段结束后，他比上一段多理解了什么？如果只是换角度或换背景，是否值得保留？
3. 他能否说出这件商品与自己有关的价值，以及考虑这一款的具体理由？
4. 这些理由由什么真实内容支持；哪里只是视觉表达，哪里有资料或实物依据？
5. 想进一步了解或选购时，能否直接完成下一步，没有被动画和操作挡住？

以上是待验证的目标，不是已经发生的销售效果。完成交付需给出实际画面和可操作结果，并说明真实检查范围。不要用“动画已实现”“构建成功”或内部高分替代顾客理解和购买路径。
