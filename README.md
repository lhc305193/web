# 杜蕾斯 AiR 网站精修交接包

这是之前已经运行的网站完整工程，接收方在此基础上继续精修。当前版本包含三维盒装、银袋、蓝色摄影棚、开盒取袋、包装旋转、3/6/16只规格选择、资料、FAQ与官方选购出口。网站尚未实现新的产品本体和完整拆封方案。

首要商业目的：吸引刚进入、原本没有兴趣的顾客，让他愿意继续看，认识实物与用途，理解价值、好处和选择理由，最终愿意进一步考虑并能顺畅选购。所有视觉、动态和交互都按这条顾客路径判断，具体见 `docs/商业目标与顾客路径.md`。

## 给朋友的使用顺序

1. 解压整个包，保留文件结构。`reference/current/` 是当前网页截图；`当前网站预览.html` 是同版可独立查看的预览，具体验证范围见 `docs/交接验证.md`。
2. 在能够读写本地项目的 Claude Code 或 Claude Desktop Code 模式中打开这个目录。
3. 将根目录 **`交给Claude.txt`** 的全文作为第一条任务发送给它。这个任务已写清背景、已有资产、精修目标、执行顺序和验收，不需要补充之前聊天。
4. 网页实际修改对象是 `src/`、`index.html`、`public/`，不要编辑压缩预览文件。

## 本地运行

需要兼容 Node.js 与 npm。项目要求 Node `^20.19.0 || >=22.12.0`；本次实际使用 Node 24.19.0。进入本目录后运行：

```sh
npm ci
npm run dev
```

以终端实际显示的本机地址为准；默认端口5190，被占用会选用其他空闲端口。保持终端运行，在浏览器打开显示的地址。停止时在终端按 Ctrl+C。

```sh
npm run build
npm run preview
```

构建输出为 `dist/`，预览默认端口5191。压缩包不携带依赖目录，接收方在本机安装；无需原作者电脑、Claude账号、API Key或其他项目目录。

## 先读哪几个文件

- `交给Claude.txt`：唯一完整的执行入口。
- `CLAUDE.md`：工程内简短约束。
- `docs/商业目标与顾客路径.md`：为什么做、面向谁、怎样从冷淡走到愿意考虑和选购，是核心验收依据。
- `docs/完整体验与视觉方案.md`：完整分镜和视觉目标，执行时以任务入口的优先级为准。
- `docs/资产与工程说明.md`：现有资产、缺口、代码地图和已知问题。
- `docs/交接验证.md`：本次交接实际做过的检查。
- `ASSET_SOURCES.md`：品牌图片与程序资产来源说明。

这是非官方创意展示，品牌与商品资料需保持准确；公开商业使用前应确认商标和素材使用范围。本包不提供下单或支付。
